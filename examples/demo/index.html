Install

Desktop: this demo sets data-desktop-qr, so the install button opens the QR dialog instead of the browser prompt. Open the QR on your phone to install there. Android/Chrome: the real beforeinstallprompt flow runs when the browser offers it.

Network diagnostics

Cloudflare DoH checks the current hostname only. JavaScript cannot inspect the device’s normal DNS resolver, and a host failure is not proof of DNS interference.

Notifications

Push needs VAPID keys and a server — see examples/push-server/. The public playground has no sender configured, so it will not send notifications.

UI components

Assistant theme

Mode

The same theme configuration for the floating Assistant: auto follows this page and the OS, light / dark pin a scheme, and custom accepts validated tokens. Invalid values are dropped field by field and reported as warnings — the Assistant never breaks.

More API tests

Share and push depend on browser support. Push sending needs VAPID keys and a backend; this public playground does not send notifications.
