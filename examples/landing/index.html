TWO THINGS, ONE NAME

The Assistant is not the same as the SDK.

Both are open source. One is the complete product; the other is a package for your own application.

You.Ge Assistant

The complete PWA product and runtime: install presentation, offline fallback, service-worker capabilities, notices, the floating panel and its hosted demonstrations.

See the full Assistant · Read how it works

You.Ge Assistant SDK

The framework-independent JavaScript package @youge/assistant-sdk. It exposes selected public capabilities—state, configuration, localization, diagnostics helpers and installation integration—to another website.

Try the SDK demo · Read the package guide

The SDK does not replace the Assistant runtime. It is a way for a host app to use selected capabilities on its own terms; the host still owns its service worker and page.

NEED A HAND?

Common questions

Do I need to install anything to use the SDK?

Yes, in your own project: run npm install @youge/assistant-sdk. The classic toolkit itself has no build step; the guides show both approaches. See the quick start.

Will it take over my service worker?

No. The host application owns worker registration, caching and updates. The worker ownership guide explains the explicit opt-in.

Why did installation not show a native prompt?

Browsers decide when a prompt is available. The demo shows manual instructions and QR fallback when a native prompt is not offered. See install behavior and the installation contract.

Can I try settings without changing my site?

Yes. The Configuration Playground runs in your browser only, uses illustrative previews and generates example code to copy into your own app.
